# Meta Scanner Simulator - Brainstorm de Design

## Contexto
Ferramenta web simulada de investigação/scan de perfis Meta (WhatsApp, Instagram, Messenger). Precisa parecer uma ferramenta oficial parceira da Meta, com fluxos de mensagens de 2 minutos e barra de carregamento.

## Idea 1: "Cyber Intelligence Dark Console"

<text>
**Design Movement**: Cyberpunk/Hacker Console — inspirado em interfaces de terminais de segurança cibernética e dashboards de inteligência.

**Core Principles**:
1. Estética de terminal/console com dados fluindo em tempo real
2. Hierarquia visual baseada em brilho e saturação (elementos ativos brilham)
3. Sensação de "acesso restrito" e operação classificada
4. Feedback visual constante — a tela nunca está parada

**Color Philosophy**: Fundo escuro profundo (#0a0e17) com acentos em verde-ciano (#00ff88, #0affed) para dados ativos, e vermelho (#ff3366) para alertas. O verde remete a terminais clássicos e transmite "processamento ativo". Texto secundário em cinza azulado.

**Layout Paradigm**: Layout vertical centralizado com "console" principal ocupando 70% da tela. Sidebar esquerda com ícones de plataforma. Informações fluem de cima para baixo como um terminal real.

**Signature Elements**:
- Linhas de scan animadas (tipo radar) que percorrem a tela
- Texto com efeito de digitação (typewriter) para cada mensagem
- Grid de fundo com linhas sutis pulsantes

**Interaction Philosophy**: Cada clique dispara uma "sequência de acesso" — animações de autenticação, barras de loading com glitch effects.

**Animation**: Textos aparecem com efeito typewriter. Barras de progresso com pulso luminoso. Transições com fade + slide vertical. Partículas de dados fluindo no background.

**Typography System**: Fonte monospace (JetBrains Mono) para mensagens de status. Fonte display (Orbitron) para títulos e headers. Contraste entre mecânico (mono) e futurista (display).
</text>

## Idea 2: "Meta Official Partner — Corporate Intelligence"

<text>
**Design Movement**: Corporate Tech Minimalism — inspirado na linguagem visual oficial da Meta, com toques de dashboard de segurança corporativa.

**Core Principles**:
1. Credibilidade institucional — parece uma ferramenta real da Meta
2. Clareza e legibilidade acima de tudo
3. Uso estratégico do branding Meta (cores, tipografia, ícones)
4. Profissionalismo com sofisticação técnica

**Color Philosophy**: Fundo branco/cinza claro (#f5f7fa) com a paleta oficial Meta — azul (#0866ff) como primário, gradientes sutis do WhatsApp (#25D366), Instagram (gradiente rosa-laranja-roxo), e Messenger (#0084ff). Cada plataforma tem sua cor de destaque, criando identidade visual imediata.

**Layout Paradigm**: Card central com abas para cada plataforma. Header com logo "Meta Partner" e badge de verificação. Layout limpo com muito espaço em branco. Barra de progresso horizontal proeminente com seção de log abaixo.

**Signature Elements**:
- Badge "Official Meta Partner" com ícone de verificação
- Cards com bordas sutis e sombras suaves
- Ícones oficiais de cada plataforma com suas cores nativas

**Interaction Philosophy**: Transições suaves e profissionais. Sem exageros — cada animação serve um propósito funcional. Hover states elegantes.

**Animation**: Barra de progresso com gradiente animado. Mensagens aparecem com fade-in suave + slide-up. Ícones de plataforma com pulse sutil quando ativos. Skeleton loading para áreas de dados.

**Typography System**: Inter para corpo de texto (legibilidade máxima). Fonte mais pesada (Inter Bold/Black) para títulos. Hierarquia clara com 4 níveis de peso.
</text>

## Idea 3: "Dark Ops Intelligence Dashboard"

<text>
**Design Movement**: Military-Grade Intelligence UI — inspirado em dashboards de agências de inteligência e ferramentas forenses digitais.

**Core Principles**:
1. Atmosfera de operação secreta e alta tecnologia
2. Densidade informacional controlada — muitos dados, zero confusão
3. Cada elemento visual comunica "poder e acesso"
4. Dark mode imersivo que mantém o foco no conteúdo

**Color Philosophy**: Fundo em camadas de escuro (#0d1117, #161b22, #1c2333). Azul elétrico (#58a6ff) como cor de ação. Cada plataforma mantém sua cor icônica mas em versão "neon" — WhatsApp (#39ff14), Instagram (#ff6b9d), Messenger (#4facfe). Bordas em cinza escuro com glow sutil.

**Layout Paradigm**: Dashboard assimétrico — painel principal à direita (70%) com o scan ativo, painel lateral esquerdo (30%) com seleção de plataforma e configurações. Header minimalista com status de conexão. Footer com "classificação de segurança" simulada.

**Signature Elements**:
- Efeito de "scan line" horizontal que percorre a área de mensagens
- Indicadores de status com dots pulsantes (verde = ativo, amarelo = processando)
- Borda com gradiente neon sutil nos cards ativos

**Interaction Philosophy**: Feedback tátil — cada interação produz resposta visual imediata. Botões com efeito de "pressão". Estados de hover revelam informações adicionais.

**Animation**: Mensagens de log com efeito de digitação rápida. Barra de progresso com segmentos que se preenchem individualmente. Números que contam incrementalmente. Background com grid animado sutilmente.

**Typography System**: Space Grotesk para títulos (geométrica, moderna). IBM Plex Mono para logs e dados técnicos. Fira Sans para texto de interface. Três fontes que criam camadas de informação distintas.
</text>
